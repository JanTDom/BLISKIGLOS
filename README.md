# BLISKIGLOS (bliskiglos.pl)

Terapeutyczny towarzysz AI dla seniorów w kryzysie samotności oraz osób z demencją (oparty na Terapii Walidacyjnej Naomi Feil i Reminiscencji).

## Szybki Start

```bash
cd /Users/macbookpro/PROJEKTY/BLISKIGLOS
npm run dev
```

Aplikacja uruchomi się pod adresem: `http://localhost:3000`.

## Wdrożenie Produkcyjne

```bash
npx vercel --prod --yes
```

Domena produkcyjna: **https://bliskiglos.pl** / **https://bliskiglos.vercel.app**
